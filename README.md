# IoT Fundamentals & Sensor Simulation

## Mission 1
This project demonstrates basic IoT architecture and simulates temperature and humidity sensor data using Python.

### Files
- `sensor_simulation.py` – Python code for generating and visualizing sensor data.
- `sensor_data.csv` – Generated sensor readings.
- `sensor_plot.png` – Visualization of temperature and humidity.
- `IoT_Architecture_Report.pdf` – Mission report.

## Technologies
Python, CSV, Matplotlib, MQTT/HTTP concepts.

## Workflow
Sensor simulation -> CSV data collection -> visualization.
